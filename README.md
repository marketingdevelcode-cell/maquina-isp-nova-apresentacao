# maquina-isp-nova-apresentacao

Apresentação comercial interativa da Máquina.ISP para eventos e feiras, totalmente autossuficiente e otimizada para uso offline.

## 🚀 Como Executar

- **Opção 1 (Recomendada):** Dê dois cliques em `Abrir apresentação.bat` para iniciar o servidor local e abrir no navegador padrão.
- **Opção 2:** Abra o arquivo `index.html` diretamente no navegador.

Consulte o arquivo `LEIA-ME - Captação de Leads.md` para obter detalhes sobre atalhos de teclado, formulário de leads e exportação para Excel.
